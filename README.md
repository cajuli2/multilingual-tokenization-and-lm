# multilingual-tokenization-and-lm

This repository contains the code for the Multilingual Language Model assignment. 

To train the tokenizer and Transformer, run the cells in `train.ipynb`.
To evaluate the saved models, run the cells in `evaluate.ipynb`

The main tables and figures from the report can be found in `results/train`, or in the output of the cells in the train/evaluate notebooks.

Saved models can be found in the `/models` and `/tokenizers` directory. 
The models ending with "_epochs20_batchsize64.pth" are the ones used in the final evaluation.
